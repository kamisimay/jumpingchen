
キャラクター投擲シミュレーションゲーム 仕様書


1. 概要

本プログラムは、HTML5 CanvasとJavaScript（Vanilla JS）を用いて開発された、Webブラウザ上で動作する物理挙動シミュレーションゲームです。
画面をタップ（またはクリック）するたびに、配置されたキャラクターが画面下部から不規則な方向・高さへ投げ上げられ、重力に従って放物線を描きながら自然に落下する、直感的で心地よいインタラクションを提供します。

2. 動作環境・動作要件

• 対応ブラウザ: 各種主要ブラウザ（Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge 等）
• 対応デバイス: PC、スマートフォン、タブレット（レスポンシブなタッチ操作に対応）
• 依存関係: なし（外部ライブラリを使用しないピュアなJavaScriptプログラム）

3. 主要機能と仕様


① 物理シミュレーション機能

• 擬似重力の実装: 一定の重力加速度（GRAVITY = 0.4）を常時キャラクターに適用し、自然な自由落下・放物線運動を再現。
• アニメーションループ: requestAnimationFrame を採用し、デバイスの画面更新レート（一般に60fps）に同期した滑らかで描画負荷の低いアニメーションを実現。

② ランダム性を備えた打ち上げ演出

画面がタップまたはクリックされるたびに、以下の要素がリアルタイムにランダム計算され、飽きない動きを演出します。
• 初期位置（左右ランダム）: キャラクターが画面外に完全にハミ出さないよう安全なマージン（横幅の半分）を確保した上で、X座標を毎回ランダムに決定。
• 発射角度（左右ランダム）: 打ち上げ時に -2.5 〜 +2.5 の間でランダムな横速度（vx）を付与し、斜め方向への多彩なジャンプを実現。
• 到達高度（高さランダム）: 垂直方向の初速度（vy）を -13 〜 -18 の間で毎回変動させ、大ジャンプや小ジャンプを不規則に発生。

③ 画像の自動背景透過処理（最適化済）

• オンザフライ透過: 背景が白（RGBがすべて240以上）のキャラクター画像を、プログラム側で読み込み時に1画素（ピクセル）ずつ走査。条件に合う画素の不透明度（アルファ値）を 0 に書き換えることで、自動で透明化。
• ワンタイム・キャッシュ化: 描画ごとのリアルタイムピクセル解析による深刻な処理落ち（コマ落ち、キャラクターの消失バグ）を防ぐため、画像読み込み時の最初の1回のみ透過処理を行い、専用の内部キャンバスに記憶して高速描画（キャッシュ）する最適化アルゴリズムを導入。

4. プログラム構成・変数

プログラム内で動作をカスタマイズするための主要な定数・変数は以下の通りです。

変数・定数名	初期値	役割・概要
GRAVITY	0.4	キャラクターにかかる重力。値を大きくすると速く落下します。
character.width / height	180	キャンバス上でのキャラクターの表示サイズ（ピクセル）。
character.vx	可変	キャラクターの現在の横移動速度。
character.vy	可変	キャラクターの現在の縦移動速度。
character.image.src	'character.png'	読み込むキャラクター画像。CORSエラー回避のためローカル参照。


5. 画面設計（UI/UX）

• 全体の背景色: #e6a76a (キャラクターの色合いを引き立てる暖色系)
• ゲームステージ（Canvas）: 500px × 600px の固定サイズ（角丸・シャドウつき）。
• 操作ガイド: ユーザーが直感的に遊べるよう、画面上部に半透明の案内テキスト「画面をタップして投げ上げる」を常時表示。

6. 今後の拡張性（アップデート案）

本プログラムの基本構造をベースに、将来的に以下の機能を容易に追加できるよう設計されています。
• 落下中にキャラクターが回転する「回転アニメーション」の追加
• 最高到達点（頂点）に達したときに画像が切り替わる「ポーズ変更機能」
• 連続でタイミングよくタップするとコンボが発生する「空中お手玉ゲーム」への発展
